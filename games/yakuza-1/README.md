# 용과 같이 1 — 배포 보류

**현재 다운로드 제공을 중단했습니다. 정식 릴리스는 게시하지 않았습니다.**

처음 확인한 거리 장면에서는 하단·오른쪽 줄이 사라졌으나, 추가 플레이에서 다음 문제가 보고되었습니다.

- 전투 후 거리로 돌아오면 하단 줄이 다시 나타남.
- PCSX2 재시작 후 패치 활성화가 해제된 것으로 보임.
- 다시 활성화하면 하단은 정상화되지만 오른쪽 줄이 남음.

장면 전환 후 보정 재적용과 활성화 상태 유지를 확인하고 있습니다. 원인을 해결하고 재확인하기 전에는 현재 시험판을 정식 배포하지 않습니다.

대상: SLPM-66168 / CRC B7B3800A / PCSX2 2.8.2 / Vulkan·4×.
