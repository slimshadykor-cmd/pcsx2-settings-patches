# 용과 같이 1 — PCSX2 전용 설정·화면 경계 보정

Vulkan·4× 해상도용 전용 설정과, 확대 렌더링에서 나타나던 **화면 하단·오른쪽의 가느다란 줄을 보정하는 v1.0 패치**입니다. 화면 자르기를 0으로 유지하면서 합성 효과가 화면 끝까지 그려지도록 보정합니다.

사용자가 테스트한 거리 장면에서 하단과 오른쪽 줄 제거를 확인했습니다. 게임 전체를 끝까지 검증한 것은 아니며, 모든 PC에서 최적의 성능이나 모든 장면의 정상 동작을 보장하는 설정은 아닙니다.

## 대상과 확인 환경

| 항목 | 내용 |
| --- | --- |
| 게임 | 용과 같이 1 / Ryu ga Gotoku, 일본판 기반 |
| 게임 시리얼 | **SLPM-66168** |
| 실행 파일 CRC | **B7B3800A** |
| PCSX2 | **2.8.2** |
| 렌더러·내부 해상도 | **Vulkan / 4×** |
| 테스트 PC | Ryzen 7 5700X / GeForce RTX 3080 12GB |
| 공개 배포 버전 | **v1.0** |

한글판으로 실행하더라도 시리얼과 CRC가 위 값과 일치해야 합니다. 다른 지역판이나 CRC가 다른 실행 파일은 검증되지 않았습니다. 이 배포물은 에뮬레이터 설정과 그래픽 보정만 포함하며, 게임 본편이나 한글패치 파일은 포함하지 않습니다.

## 설치

1. **게임을 완전히 종료**합니다.
2. PCSX2에서 **도구 → 데이터 디렉터리 열기**로 실제 데이터 폴더를 확인한 뒤 PCSX2도 종료합니다. 설치 폴더와 데이터 폴더는 다를 수 있습니다.
3. 동일한 이름의 기존 파일이 있으면 다른 폴더에 백업합니다. 이 설정파일로 교체하면 해당 게임의 기존 개별 설정도 바뀔 수 있으므로, 직접 설정한 항목이 있다면 먼저 백업하세요.
4. `.ini`는 `gamesettings`, `.pnach`는 `patches`에 각각 넣습니다. 폴더가 없다면 만드세요. 전역 설정파일 `PCSX2.ini`를 덮어쓰지 않습니다.
5. PCSX2를 다시 열고 게임의 **속성 → 패치 → 다시 불러오기**에서 **`Bottom and Right Edge Fix v1.0`**을 켭니다. 이전 시험판과 표시 이름이 달라졌으므로 새 항목을 켜 주세요.
6. **Vulkan / 4×**, **오른쪽·하단 자르기 0**을 확인하고 게임을 실행합니다.

명령 프롬프트나 Python을 실행할 필요는 없습니다.

### 패치가 치트 목록에 표시될 때

설정의 치트 검색 경로가 `patches` 폴더를 가리키면 치트로도 검색될 수 있습니다. **도구 → 데이터 디렉터리 열기**로 찾은 `patches` 폴더에 이번 파일을 두고, 치트 검색 폴더에 남아 있는 이 게임의 동일한 구버전 파일은 별도 백업 폴더로 옮기세요. 다른 게임 파일이나 전역 치트 경로를 일괄 변경할 필요는 없습니다.

## 적용 내용

**전용 설정파일**은 Vulkan, 내부 해상도 4×, 블렌딩 정확도 Full, PS2 방식 텍스처 필터링, 전체 텍스처 사전 불러오기를 사용합니다. 자동 게임 호환성 보정을 켜고 수동 하드웨어 보정은 끕니다. 상하좌우 자르기 값은 모두 0이며, 세로 확대는 100%입니다.

**v1.0 패치**는 화면 합성에 사용되는 사각형의 하단과 오른쪽 끝 좌표를 원본 기준 0.5픽셀 늘립니다. 하단 좌표 88개와 가장 오른쪽 끝 좌표 6개를 수정하며, 중간 구간의 가로 경계와 텍스처 좌표는 유지합니다. 끝 구간의 보간에는 미세한 변화가 생길 수 있습니다.

하단·오른쪽 보정이 통합돼 있으므로 **v1.0 하나만 사용**합니다. 확인된 v0.3 시험판의 보정 명령은 그대로이며, 공개 배포명과 설명만 정리했습니다. v0.1과 함께 사용하지 마세요. 게임 ISO나 메모리카드 파일 자체를 직접 수정하는 방식은 아닙니다.

## 저장 상태와 되돌리기

- 처음 확인할 때는 타이틀부터 시작해 게임의 메모리카드 저장을 불러오는 방법이 가장 명확합니다.
- v0.2만 적용한 저장 상태는 하단 보정을 유지하면서 오른쪽 보정을 추가하도록 구성했습니다. v0.3의 수정값은 v1.0과 같으므로 그대로 유지됩니다.
- **v0.1을 켠 채 만든 저장 상태는 사용하지 마세요.** 이전 코드가 메모리에 남을 수 있으며 v1.0은 그 코드가 감지되면 적용하지 않습니다.
- 패치를 켠 채 만든 저장 상태에는 변경된 메모리가 남을 수 있습니다. 체크를 끄는 것만으로 그 상태의 수정값이 복구되지는 않습니다.
- 되돌리려면 게임을 종료하고 패치를 끈 뒤, 타이틀부터 메모리카드 저장을 불러오거나 패치 적용 전 저장 상태를 사용하세요. 전용 설정도 되돌리려면 백업한 `.ini`를 복원하세요.

## 확인된 범위

- PCSX2 2.8.2, Vulkan·4× 환경에서 테스트한 거리 장면의 **하단 줄 제거 확인**.
- 같은 환경에서 **오른쪽 줄 제거 확인**.
- v1.0의 실제 패치 명령과 설정값은 확인된 v0.3 시험판 및 기존 전용 설정과 동일합니다. 공개용 파일에서는 설명과 확인 상태만 갱신했습니다.
- 실내·전투·메뉴·영상과 게임 전체 진행에 대한 검증은 완료되지 않았습니다.

문제가 있으면 게임 시리얼·CRC, PCSX2 버전, 렌더러·배율, 문제가 생긴 장면과 스크린샷을 함께 알려 주세요.
